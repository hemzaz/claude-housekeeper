# Vocabulary

Housekeeper needs two vocabularies:

- internal doctrine words
- user-facing report words

## 1. User-Facing Words

Use in CLI/report output:

- no files changed
- protected by rule
- outside declared scope
- live probe required
- missing key
- review required
- candidate stale cache
- expected orphan
- blocked by rollback proof
- scan degraded
- next safe step

## 2. Internal/Docs Words

Use in philosophy/spec docs:

- sector boundary
- no-fire zone
- haunted
- possession
- entropy
- evidence key
- claim ladder
- authority ladder
- surface gate

## 3. Avoid In Reports

Avoid:

- junk
- trash
- deletion-ready
- unused, unless proven
- auto-fix
- guaranteed rollback
- haunted, unless marketing/docs context
- possession, unless internal docs

## 4. Translation Table

| Internal | User-facing |
| --- | --- |
| sector boundary | protected/outside allowed action |
| evidence key | required evidence |
| haunted | confusing/broken behavior |
| possession | active old actor |
| entropy | accumulated drift |
| candidate stale cache | candidate stale cache |
| expected orphan | expected orphan |
| checkpoint-only | rollback proof missing |
